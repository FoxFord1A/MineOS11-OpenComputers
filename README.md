# MineOS 11 для OpenComputers

Оболочка рабочего стола в стиле Windows 11 для OpenComputers/OpenOS с текстовым HTTP(S)-браузером. Установщик запускается прямо из OpenOS.

## Возможности и ограничения

- Рабочий стол, кликабельная панель задач и меню «Пуск».
- Кнопка `[WWW]` на панели или значок рабочего стола открывают браузер.
- Кнопка `[POWER]` открывает меню выключения/перезагрузки компьютера.
- Браузер загружает HTTP(S)-страницы через Internet Card, показывает заголовок страницы, очищенный текст, HTTP-код ответа и до 9 ссылок.
- Кнопки назад/вперёд/обновить, прокрутка и переход по ссылкам цифрами `1`–`9`.
- Это **не полноценный современный браузер**: JavaScript не исполняется, CSS и изображения не отображаются. OpenComputers предоставляет HTTP API, а не движок Chrome/Firefox.
- Для веб-доступа нужна Internet Card и разрешённые HTTP-запросы в конфигурации OpenComputers.

## Установка с GitHub из OpenOS

Репозиторий: <https://github.com/FoxFord1A/MineOS11-OpenComputers>.

В OpenOS выполните:

```sh
wget -f https://raw.githubusercontent.com/FoxFord1A/MineOS11-OpenComputers/main/mineos-install.lua /home/mineos-install.lua
lua /home/mineos-install.lua
```

Установщик загружает приложение в `/home/mineos.lua`; предыдущую версию сохраняет в резервный файл. Запустите оболочку:

```sh
lua /home/mineos.lua
```

## Управление браузером

- Нажмите `[WWW]`, значок `Браузер` или пункт меню «Пуск».
- Нажмите на белое поле адреса, введите URL и нажмите Enter или `[GO]`.
- `[<]`, `[>]`, `[R]` — назад, вперёд, обновить; **Esc** — рабочий стол; **↑/↓** — прокрутка.
- Ссылки в тексте показываются как `[1]`, `[2]` и т.д.; нажмите соответствующую цифру на клавиатуре, чтобы перейти.
- При ошибке проверьте сообщение и HTTP-код в нижней строке окна. Частые причины: Internet Card отсутствует, интернет/HTTP запрещены настройкой мода, сайт недоступен из среды игры.

## Управление питанием

Нажмите `[POWER]` и выберите «Выключить компьютер», «Перезагрузить» или «Отмена».

## Публикация

Репозиторий публичный, чтобы OpenOS мог скачать исходники с `raw.githubusercontent.com` без токена. Код доступен всем; не загружайте пароли, токены и личные данные.
